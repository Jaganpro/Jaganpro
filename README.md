## ⚙️ My setup: [.dotfiles](https://github.com/Jaganpro/.dotfiles)

[![.dotfiles](https://img.shields.io/badge/Jaganpro-.dotfiles-d79921?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Jaganpro/.dotfiles)
![macOS](https://img.shields.io/badge/macOS-Apple_Silicon-000000?style=for-the-badge&logo=apple&logoColor=white)
![Gruvbox](https://img.shields.io/badge/theme-Gruvbox_Dark-282828?style=for-the-badge)

My macOS setup, built for working alongside AI agents. One command (`dot init`) sets up a new Mac:

- 🖥️ **Terminal:** [Rex](https://www.superlogical.com/rex) · zsh · starship · fzf · Gruvbox Dark everywhere
- 🤖 **Two agents, one brain:** [Pi](https://pi.dev) and Claude Code share skills, slash commands and coding rules
- 🧩 **Custom Pi extensions:** web search with fallbacks, git-guard, a context-aware footer, run stats, and wine facts while it works 🍷
- 📝 **Review loop:** `/annotate` plans and `/review` diffs in the terminal; feedback goes straight back to the agent
- 🔒 **Guardrails:** shellcheck, lint and gitleaks on every commit, and agents can't skip them
- 🩺 **Self-checking:** `dot doctor` finds broken links, missing packages and unpushed work
